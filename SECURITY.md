# Política de Segurança

Este é um projeto educacional/de portfólio (página estática em HTML/CSS/JS). Não há suporte formal nem garantia de prazo de correção, mas levo a sério qualquer problema reportado.

## Como reportar uma vulnerabilidade

- Se a aba **Security** do repositório exibir **Report a vulnerability**, use essa opção (GitHub Security Advisories) para um relato privado.
- Caso contrário, abra uma [issue](https://github.com/DenisPaulo/projeto-mapadev-week/issues) descrevendo o problema **sem incluir dados sensíveis** (credenciais, chaves, dados pessoais ou passos de exploração detalhados). Se necessário, peço mais detalhes pela própria issue.

## Segredos e credenciais

Nunca faça commit de chaves, senhas, tokens ou dados pessoais. Use um arquivo `.env` local (já ignorado pelo Git) e variáveis de ambiente quando o projeto precisar delas. Se encontrar um segredo exposto neste repositório, avise pela forma acima e não o reutilize.
